# CAIS 2026 · Semana 12 · Retos de vibe coding

Repositorio del equipo para los 5 retos de vibe coding sobre una misma aplicación: **Veterinaria del Barrio**, una app web para que una clínica veterinaria de barrio lleve el control de sus pacientes y sus visitas.

Cada reto vive en su propia carpeta, con su app, su README (qué hace, cómo correrla en 5 minutos y cómo verificarla), sus pruebas y sus evidencias.

## Cómo correr la versión más reciente en 5 minutos

1. `git clone https://github.com/Anderfg13/cais-vibe-coding-challenge.git`
2. Abre `reto1/app/index.html` con doble clic. No hay que instalar nada.

Los detalles y la verificación de cada reto están en el README de su carpeta.
